How to Run the Notebook

Prerequisites

Ensure you have Python installed along with the required libraries. You can install the necessary dependencies using pip:

pip install -r requirements.txt

(Note: If you don't have a requirements.txt file, you can install common packages directly, e.g., pip install jupyter pandas numpy matplotlib scikit-learn)

Execution Steps

Launch Jupyter Notebook or JupyterLab:

jupyter notebook

(Alternatively, open the directory in Visual Studio Code or upload to Google Colab).

Open the main notebook file (.ipynb).

Select the appropriate Python kernel.

Run all cells sequentially from top to bottom by clicking Cell > Run All (or Runtime > Run all in Google Colab).
